## Description
This image shows about the TB Burden by region, estimated average value of prevalence high bound, low bounds. Moreover, EU has highest detection rate among all regions by percentage. And, you can see the methods to derive incidents (estimate) by Region. There are 219 implementation countries, six by Region.
